Privacy, plainly.

This page describes the intended local-playback model. Website hosting, release distribution, and the application itself may process technical data differently; update this policy if you add analytics, telemetry, crash reporting, or other services.

Video files and local playback

FocusMediaPlayer is designed to open video files stored on the user's own device. This website does not provide video uploads, cloud video storage, or streaming of your personal library. Do not treat this statement as a guarantee about future versions or third-party components; review the release and its dependencies.

Internet access

Local playback is intended to work offline after installation. Visiting this website, downloading the installer, and opening GitHub release pages require an internet connection. The website host and GitHub may process technical request data under their own privacy policies.

Cookies and analytics

This starter website does not intentionally include advertising trackers, analytics scripts, or third-party embeds. The hosting provider may still collect server logs. If analytics, forms, or other external services are added later, this section should be updated.

Third-party services

The download button links to GitHub Releases. GitHub processes visits and downloads under its own policies and terms. FocusMediaPlayer is not affiliated with Microsoft or GitHub.

Contact

For product issues, use the GitHub Issues page. Avoid publishing personal information or sensitive files in public issue reports.
