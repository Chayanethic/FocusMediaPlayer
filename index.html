OmniVideoPlayer is built around the simple things that make long videos easier to work through: organised playback, useful controls, and a way to set boundaries around your session.

▶

Comfortable playback

Watch local videos with familiar playback controls, seeking, volume, speed adjustment and fullscreen viewing.

☷

Playlists for long courses

Keep related lectures together so you can move through a course or revision collection without constantly hunting for the next file.

◎

Strict Focus Mode

Start a timed focus session and reduce the temptation to casually leave the player. Focus features are designed to support—not replace—your own study habits.

Study at your pace

Move through familiar material quickly or slow down for a difficult explanation. Your learning pace does not have to match the original recording.

Good to know

Questions, answered.

Is OmniVideoPlayer free?

Yes. The v1.0.0 Windows release is offered as a free download. Check the GitHub release page for the published build and notes.

Does it need an internet connection to play videos?

Normal playback of local files is designed to work offline after installation. Downloading the installer and checking for updates requires internet access.

Do I need Python or VLC installed separately?

The installer is intended to bundle the runtime components required by the application. It has been packaged with VLC libraries; test the installer on a clean Windows PC before relying on that claim for every system.

Does Focus Mode make my computer impossible to exit?

No. Focus Mode is an in-app feature intended to discourage casual exits during a session. It is not a Windows kiosk, parental-control or tamper-proof lock.

Does OmniVideoPlayer upload my video files?

The player is intended for local playback, not video hosting. Your files are opened from your device; this website does not provide video uploads or cloud playback.

Why might Windows show a security warning?

New or unsigned Windows applications can trigger Smart App Control or other reputation-based warnings. Publishing on GitHub does not automatically remove those warnings. Only install software you trust and review the source and release details.
